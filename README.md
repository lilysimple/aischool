# Контент-агент для Telegram-канала

Учебный проект AI School. Агент ведёт Telegram-канал: находит поводы,
предлагает идеи, пишет пост, подбирает фотографию, собирает обложку
с плашкой и после согласования публикует.

Программировать не нужно — весь код здесь. Работа студента в другом:
принести материалы о себе и править текстовые инструкции агента.

## Что делает агент

Один прогон — один пост. Человек согласовывает четыре раза:

1. **Идея.** Агент ищет свежие поводы, сверяется с историей тем
   и присылает четыре варианта в Telegram. Вы отвечаете номером.
2. **Текст.** Пишет пост в вашем голосе, с оформлением, в лимите
   Telegram. Правки — сколько нужно.
3. **Фотография.** Подбирает 2–3 подходящих снимка из вашей папки
   и присылает на выбор.
4. **Обложка.** Кладёт на выбранное фото плашку с заголовком
   и показывает. После «ок» пост уходит в канал.

Обложка не генерируется нейросетью: берётся ваша фотография, поверх
ложится свёрстанная HTML-плашка, со страницы снимается скриншот.
Поэтому результат предсказуем, а поправить отступ — это одна строка CSS.

## Структура

```
.claude/skills/     что агент умеет — обычный текст, правится руками
  brand-setup/      собирает бренд-профиль из ваших материалов
  idea-finder/      ищет поводы и предлагает темы
  post-writer/      пишет текст поста
  cover-designer/   подбирает фото, собирает обложку, публикует
scripts/            чем агент действует
  tg_whoami.py         узнать свой chat_id
  tg_ask.py            задать вопрос и дождаться ответа
  tg_ask_photo.py      прислать фото на выбор
  render_cover.py      собрать обложку
  publish_telegram.py  опубликовать пост
templates/cover.html   вёрстка плашки поверх фото
input/              ваши материалы (см. ниже)
brand/              кто мы и как говорим — собирается агентом
state/              память: какие темы и фото уже были
prompts/examples.md исходные промпты и разбор, как они стали скиллами
docs/homework.html  инструкция к заданию
```

## Что приносит студент

| Файл | Что внутри |
|---|---|
| `input/about.md` | о чём канал, о себе или о продукте, портрет аудитории |
| `input/my-texts.md` | 2–5 своих текстов целиком — с них снимается голос |
| `input/refs/` | 3–8 примеров оформления, которое нравится |
| `input/photos/` | 10–30 своих фотографий для обложек |

Качество постов на 80% определяется этими входами, а не моделью
и не промптами.

## Установка

Нужны Python 3.10+, Node.js 18+ и аккаунт Claude с доступом
к Claude Code. Ключ Anthropic API не нужен — хватает подписки Pro или Max.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium

npm install -g @anthropic-ai/claude-code

cp .env.example .env    # и заполнить
```

`.env` в репозиторий не попадает и попасть не должен: токен бота даёт
полный доступ к нему. Если случайно опубликовали — `/revoke` у @BotFather.

## Запуск

```bash
source .venv/bin/activate
claude
```

Дальше обычной фразой:

```
Найди темы для поста на сегодня
```

Скилл не называется по имени и путь к файлу не указывается: Claude Code
сам сопоставляет фразу с описанием скилла.

Подробная инструкция со скриншотами — в `docs/homework.html`.
