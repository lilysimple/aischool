# Контент-агент Telegram-канала

Агент ведёт Telegram-канал: находит поводы, пишет пост, подбирает фото,
собирает обложку с плашкой и после согласования публикует.

## Где что лежит

- `.claude/skills/` — что агент умеет. Обычный текст, правится руками.
- `scripts/` — чем агент действует: спросить автора, собрать обложку, опубликовать.
- `templates/cover.html` — вёрстка плашки поверх фото.
- `brand/` — кто мы и как говорим. Собирается скиллом brand-setup.
- `input/` — материалы автора: about.md, my-texts.md, refs/, photos/.
- `state/ideas-history.jsonl` — память: какие темы и фото уже были.
- `output/<дата>/` — готовый пост: post.html, meta.json, cover.png.

## Правила, общие для всех скиллов

1. Человек согласовывает четыре раза: идея, текст, фото, обложка.
   Ни один из этих шагов не пропускается, даже если результат кажется
   очевидно хорошим.
2. Факты и цифры берутся только из источников. Ничего не додумывается.
3. После публикации в `state/ideas-history.jsonl` дописывается строка.
   Без этого агент завтра предложит ту же тему и то же фото.
4. Лимит поста — 1024 знака видимого текста. Это ограничение Telegram
   на подпись к фотографии, а не пожелание по стилю.
5. Общение с автором идёт в Telegram через scripts/, а не в терминале.

## Запуск

```
source .venv/bin/activate
claude
```

Дальше обычной фразой: «Найди темы для поста на сегодня».
