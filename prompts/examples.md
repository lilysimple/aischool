# Примеры промптов и как они стали скиллами

Этот файл — учебный. Он показывает, откуда взялись четыре скилла в
`.claude/skills/`. Каждый из них начинался с обычного промпта, который
приходилось копировать в чат руками каждый день.

Читайте по парам: сначала то, что вы писали бы вручную, потом — что
с этим стало и почему.

---

## Промпт 1 → скилл `brand-setup`

**Как это выглядит промптом:**

```
Прочитай input/about.md, input/my-texts.md, картинки из input/refs/
и фотографии из input/photos/.

По about.md собери brand/concept.md: о чём канал одним предложением,
портрет аудитории, 3-4 её боли словами автора, шесть рубрик с короткими
именами, стоп-темы и одно целевое действие. Если чего-то в файле нет -
спроси меня, не выдумывай.

По my-texts.md собери brand/voice.md: как автор строит фразу, 10-15 его
характерных оборотов с примерами, минимум 10 стоп-слов - оборотов,
которых в его текстах нет ни разу, и как он оформляет текст.

По картинкам из refs/ определи цвета и размеры и поправь CSS-переменные
в templates/cover.html. Разметку не трогай.

Фотографии из photos/ опиши в index.json: что на них и есть ли внизу
место под плашку.
```

**Что изменилось при переносе в скилл:**

- добавилась проверка входов в начале — если файла нет, агент
  останавливается, а не работает вхолостую;
- появились примеры «так не надо / так работает» — без них модель
  описывает аудиторию общими словами;
- перечислен точный список CSS-переменных, которые можно менять,
  и прямой запрет трогать `id` элементов: их ждёт `render_cover.py`;
- появился критерий готовности внизу — иначе агент останавливается
  на середине и считает работу сделанной.

## Промпт 2 → скилл `idea-finder`

**Как это выглядит промптом:**

```
Прочитай brand/concept.md и state/ideas-history.jsonl.

Поищи в интернете свежие поводы по темам рубрик за последнюю неделю.
Предложи мне четыре идеи поста, которых нет в истории. Для каждой:
заголовок, зачем это аудитории (с привязкой к конкретной боли),
что внутри и ссылка на источник.

Цифры и факты бери только из источников. Ничего не придумывай.

Отправь список мне в телеграм через python3 scripts/tg_ask.py
и дождись ответа.
```

**Что изменилось при переносе в скилл:**

- уточнилось правило про историю: тема считается повтором по сути,
  а не по формулировке — иначе агент переставляет слова и выдаёт
  старое за новое;
- добавилось «четыре пересказа одной новости — это одна идея»;
- ограничилось число уточняющих вопросов, иначе агент зацикливается
  на переспрашивании.

## Промпт 3 → скилл `post-writer`

**Как это выглядит промптом:**

```
Прочитай brand/voice.md и brand/concept.md.

Напиши пост по выбранной теме: первая строка ради остановки скролла,
узнавание, суть, конкретика, один выполнимый шаг, целевое действие.

Уложись в 1024 знака. Оформи тегами, которые понимает Telegram:
b, i, u, s, code, pre, a, blockquote, tg-spoiler. Списков в телеграме нет.

Придумай заголовок для плашки до 90 знаков и кикер до 24.

Покажи мне всё через tg_ask.py, правь по замечаниям, после "ок" сохрани
в output/<дата>/post.html и meta.json.
```

**Что изменилось при переносе в скилл:**

- у лимита появилась причина: «1024 знака — это ограничение Telegram
  на подпись к фото, длиннее сообщение просто не отправится».
  Правило с понятным последствием модель соблюдает заметно точнее;
- добавилось уточнение, что теги в лимит не считаются, а считается
  видимый текст — иначе агент режет хороший текст зря;
- список разрешённых тегов дополнен списком запрещённых: модель
  по привычке вставляет `<ul>` и `<h2>`, которых в Telegram нет;
- появилось правило «жирным — одну мысль на пост»: без него агент
  выделяет половину текста, и выделение перестаёт работать;
- добавилась проверка длины командой перед передачей дальше.

## Промпт 4 → скилл `cover-designer`

**Как это выглядит промптом:**

```
Посмотри input/photos/index.json и подбери 2-3 фото под тему поста.

Пришли их мне на выбор:
python3 scripts/tg_ask_photo.py <фото1> <фото2> --question "Какое ставим?"

На выбранное наложи плашку:
python3 scripts/render_cover.py <фото> --title "..." --kicker "..." \
  --out output/<дата>/cover.png

Открой картинку и посмотри сам: не вылез ли текст, читается ли он.
Покажи мне, дождись "ок", потом опубликуй:
python3 scripts/publish_telegram.py output/<дата>

Допиши тему и имя фото в state/ideas-history.jsonl.
```

**Что изменилось при переносе в скилл:**

- добавилось «проверь сам, до автора» — иначе агент показывает
  сломанные картинки и тратит ваше время;
- появились критерии подбора фото: не спорит с темой, есть место
  под плашку, не повторяется с последними пятью постами;
- разделены два случая: заголовок длиннее лимита (сокращать текст)
  и заголовок в лимите, но вылезает (чинить CSS);
- прямо запрещено выбирать фото за автора, даже когда один вариант
  кажется очевидным;
- запись в историю названа обязательной с объяснением, что сломается
  без неё.

## Что здесь общего

Промпт превращается в скилл добавлением четырёх вещей:

1. **Проверка входов** — что должно существовать до начала работы.
2. **Причина у каждого правила** — «до 1024 знаков, иначе Telegram
   не примет сообщение» работает лучше, чем «до 1024 знаков».
3. **Разбор пограничных случаев** — что делать, если автор ответил
   непонятно, если файла нет, если картинка сломалась.
4. **Критерий готовности** — по какому признаку работа закончена.

Плюс `description` в шапке файла: по нему Claude Code решает, когда
скилл вообще запускать. Описание из общих слов приводит к тому, что
скилл не срабатывает или срабатывает не вовремя.
