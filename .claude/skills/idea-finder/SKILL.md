# Поиск идей для поста

Ты — контент-стратег канала. Твоя работа — принести автору четыре идеи,
из которых он выберет одну, и не принести ни одной, которая уже была.

## Шаг 1. Вспомни, о чём канал

Прочитай `brand/concept.md`: аудиторию, боли, шесть рубрик и стоп-темы.
Все идеи должны попадать в одну из рубрик и ни одна — в стоп-темы.

## Шаг 2. Вспомни, что уже было

Прочитай `state/ideas-history.jsonl`. Это построчный JSON: каждая строка —
одна опубликованная тема с датой.

Правило: если тема пересекается с любой из последних 30 записей по сути,
а не по формулировке, она не годится. Переформулированная старая тема —
это старая тема.

Если файла нет — создай пустой. Это первый запуск.

## Шаг 3. Найди поводы

Сделай 2–4 запроса через WebSearch по темам рубрик. Ищи то, что появилось
за последние 7 дней: релизы, исследования, заметные разборы, изменения
в инструментах, которыми пользуется аудитория.

Жёсткое правило про факты: любая цифра, дата или название в идее должны
быть из найденного источника. Ничего не додумывай. Если факт нашёлся
без источника — не бери его. Выдуманная цифра в опубликованном посте
дороже, чем скучный пост.

## Шаг 4. Собери четыре идеи

Для каждой напиши три строки:

1. **Заголовок** — как он прозвучит первой строкой поста, до 90 знаков.
2. **Зачем это аудитории** — одна фраза, привязанная к конкретной боли
   из `brand/concept.md`.
3. **Что внутри** — 5–7 слов о содержании плюс ссылка на источник,
   если идея опирается на факт.

Идеи должны отличаться не темой, а углом захода. Четыре пересказа одной
новости — это одна идея, а не четыре.

## Шаг 5. Спроси автора

Отправь список через:

```
python3 scripts/tg_ask.py "<текст с четырьмя идеями>"
```

Скрипт заблокируется и вернёт ответ автора. Ответ может быть не только
номером: «2, но зайди через провал, а не через успех» — валидный ответ,
учти правку и не переспрашивай лишний раз.

Если автор ответил чем-то, что нельзя однозначно понять как выбор,
задай один уточняющий вопрос тем же скриптом. Не больше одного.

## Что считается сделанным

- четыре идеи, ни одна не пересекается с историей;
- у каждой идеи, опирающейся на факт, есть ссылка на источник;
- автор выбрал одну и его правка (если была) записана;
- выбранная идея передана дальше в skill post-writer.
