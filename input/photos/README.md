# Папка фотографий

Положите сюда 10-30 своих фотографий (JPG или PNG). Из них агент будет
собирать обложки постов: берёт снимок, кладёт поверх текстовую плашку
с заголовком и публикует.

Выбирать фото под конкретный пост будете вы: агент подберёт 2-3 подходящих
по смыслу и пришлёт их в Telegram, вы ответите номером.

Что стоит класть:
- горизонтальные или квадратные кадры — вертикальные обрежутся сверху и снизу;
- снимки со спокойным низом кадра: внизу ляжет плашка с заголовком,
  и деталь, попавшая под неё, будет не видна;
- разные по сюжету и настроению, чтобы было из чего выбирать;
- нормального разрешения, не меньше 1080 пикселей по короткой стороне.

Чего лучше не класть:
- скриншоты с мелким текстом — под плашкой он превратится в кашу;
- фотографии, где важное происходит ровно по центру нижней трети.

После первого запуска скилла `brand-setup` рядом появится `index.json`
с описанием каждого снимка. Он нужен, чтобы агент не пересматривал
всю папку заново перед каждым постом. Добавили новые фото — попросите
агента обновить опись.

---

`example.jpg` — демонстрационный файл, на нём работает проверка рендера
в шаге 6. Когда положите свои снимки, его можно удалить.
