# Папка референсов оформления

Положите сюда 3-8 картинок (PNG или JPG) — примеры оформления, которое
вам нравится: чужие посты с плашками, обложки, афиши.

Что с ними произойдёт: агент посмотрит их и по ним настроит CSS-переменные
в `templates/cover.html` — цвет и прозрачность плашки, акцентный цвет,
крупность заголовка, скругления. Сами картинки в ваши посты не попадут
и не будут срисованы: из них берётся только стилистика.

Не путайте с папкой `input/photos/` — там лежат ваши фотографии, которые
станут фоном обложек. Здесь только образцы оформления.

Что стоит класть:
- примеры с текстом поверх картинки, а не просто красивые фото;
- 3-8 штук, все в одном стиле — если стили разные, агент усреднит
  их в невнятное;
- скриншоты нормального разрешения, не мыло.
